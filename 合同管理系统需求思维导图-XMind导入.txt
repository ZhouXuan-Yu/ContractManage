通用合同管理系统
	功能
		合同中心【一期】
			工作台
				合同概况（4 个指标卡片）
					合同总数：口径＝当前用户有权限查看且未软删除的合同（未软删除不等于未作废；作废合同仍可查看，但不计入有效合同统计）；钻取＝点击进入全部有效合同台账
					草稿数量：口径＝业务状态为草稿、且未提交或已驳回或已撤回审批的合同（审批中虽为草稿但不计入）；钻取＝点击进入草稿筛选台账
					待签署数量：口径＝业务状态为待签署；钻取＝点击进入待签署筛选台账
					履行中数量：口径＝业务状态为履行中；钻取＝点击进入履行中筛选台账
					公共规则：作废合同可查看但不计入任一卡片
					布局分工：卡片只放存量指标；即将到期、待处理AI等属于待办，放入下方「待处理事项」列表
				待处理事项
					内容：即将到期合同 / 待补充合同信息 / AI待确认或失败 / 待签署文件
					数量展示：即将到期数量 / 待处理AI任务数量作为事项数量显示，不单独占用核心指标卡片
					操作：查看事项 / 进入合同详情 / 继续处理
					规则：只展示当前用户有权限处理的事项；每项必须能定位到合同和具体处理动作
				快捷入口
					操作：新建合同 / 从常用模板发起 / 导入合同 / 查看合同台账
					规则：快捷入口不重复建设业务功能，只跳转到标准页面
				最近更新
					列表内容：合同编号 / 合同名称 / 合同类型 / 生命周期状态 / 最近操作 / 更新时间
					操作：查看详情
			合同台账
				页面上下文：合同大类选择器（全部合同 / 用工与人员类 / 交易合作类 / 资产与资金类 / 权利与成果类 / 其他自定义类）
				类型切换：进入大类后以顶部Tab展示有权限的合同类型；全部合同展示当前用户全部有权限的合同
				列表内容：合同编号 / 合同名称 / 合同大类 / 合同类型 / 合同子类型 / 交易对方 / 合同金额 / 生命周期状态 / 外部审批状态 / AI处理状态 / 签署日期 / 到期日期 / 更新时间
				查询条件：合同编号或名称 / 合同分类 / 交易对方 / 生命周期状态 / 外部审批状态 / AI解析或审查状态 / 日期范围 / 金额范围
				操作：新建合同 / 导入合同 / 查看详情 / 导出当前合同 / 批量导出【按权限】
				批量操作：批量导出前校验数据权限和导出字段权限；导出任务记录操作者、筛选条件、字段范围和文件地址
				状态展示：业务状态、外部审批状态、AI解析状态、AI审查状态分开显示，不用一个状态字段代替全部状态
				钻取：点击合同进入详情；点击交易对方查看合同中的主体引用；点击AI状态进入AI页签；点击审批状态查看外部审批关联
				规则：未软删除是数据保留条件，不等于合同未作废；作废是合同业务状态，不是权限过滤条件，作废合同默认可按权限查看但不参与有效业务统计；列表只展示当前用户有权限查看的合同
			合同创建与登记
				选择来源：模板起草 / 文件导入 / 手工录入 / 外部系统同步
				选择分类：合同大类 / 合同类型 / 合同子类型；加载类型模板、类型扩展字段和AI规则
				填写主体：选择我方主体 / 选择我方角色 / 从外部主体系统选择交易对方 / 选择合同中的主体身份 / 查看主体当前信息
				填写内容：通用合同内容 / 类型专属内容 / 合同正文 / 原始文件 / 证明材料
				模板生成：选择模板后，系统根据字段字典填充变量并生成合同草稿；人工确认和编辑后保存正文版本
				通用属性：合同编号和名称 / 合同分类 / 我方主体和我方角色 / 交易对方 / 金额和币种 / 签署生效到期日期 / 正文和附件 / 合同状态和版本
				类型扩展示例：劳动合同（期限、试用期、岗位、薪酬） / 采购合同（标的、交付、验收、质保） / 租赁合同（租赁物、租期、租金、押金） / 保密协议（保密范围、期限、例外、违约）
				字段显示规则：先加载通用字段，再按合同类型和子类型加载专属字段；模板只能引用当前类型可用字段，不能自行创建业务字段
				操作：保存草稿 / 保存并继续 / 取消创建
				校验：类型必须启用 / 外部主体必须可用 / 通用和类型必填内容完整 / 正文或原始文件至少存在一种
				结果：创建合同草稿 / 记录合同来源 / 生成内容版本 / 记录创建人和时间
				规则：草稿允许分步保存；提交前再次校验类型版本、主体可用性、正文版本和必要附件
			合同详情与生命周期
				顶部摘要：合同名称和编号 / 合同类型 / 生命周期状态 / 外部审批状态 / AI风险等级 / 合同金额 / 签署日期 / 到期日期
				概览页签：通用信息 / 合同分类 / 我方主体 / 交易对方引用 / 主体当前信息 / 关键时点快照 / 下一步可执行动作
				正文与版本页签：正文预览 / 原始文件 / 当前有效版本 / 草稿版本 / 历史版本 / 版本差异 / 内容摘要
				条款与履行页签：AI解析条款 / 合同标的 / 交付验收 / 履行事项 / 条款确认状态
				收付款页签：收付款计划 / 计划条件 / 已收付记录 / 收付状态 / 逾期标记
				智能与审批页签：AI解析结果 / AI法律审查 / 外部审批关联 / 审批同步记录 / 最近一次有效结果
				附件与变更页签：原始文件 / 签署文件 / 证明材料 / 变更协议 / 补充协议 / 文件版本
				附件操作：上传 / 预览 / 下载 / 删除【按权限】/ 查看文件版本
				操作记录页签：合同操作 / AI任务 / 文件访问 / 外部审批同步 / 版本变化
				操作按钮：编辑草稿 / 发起AI解析 / 发起AI审查 / 提交外部审批 / 撤回审批 / 上传签署文件 / 撤回签署 / 确认签署生效 / 标记完成 / 发起变更 / 发起补充协议 / 导出打印 / 作废 / 终止
				操作规则：只显示当前状态和权限允许的动作；动作执行前校验前置条件；执行成功后刷新状态、时间线和下一步动作
				锁定规则：审批中和待签署锁定主体、金额、正文、类型扩展字段和付款计划；驳回或撤回后恢复编辑
			AI任务列表
				列表内容：合同 / 任务类型 / 任务状态 / 合同版本 / 风险等级 / 发起人 / 更新时间 / 失败原因
				查询条件：任务类型 / 任务状态 / 风险等级 / 合同类型 / 时间范围
				操作：查看合同 / 查看原文依据 / 确认结果 / 修正结果 / 重发任务
				规则：AI任务异步执行；结果绑定合同内容版本；旧版本结果不能覆盖新版本；失败不阻断合同保存
				AI职责：合同解析把文本转换为结构化字段、条款、标的和付款计划；法律审查识别风险并提供原文依据和修改建议；AI不审批、不签署、不改变合同状态
				与模板关系：模板引擎负责生成正式合同草稿；AI负责生成后的字段校验、内容解析和风险审查
			合同履行台账
				履行列表：合同 / 交易对方 / 履行状态 / 到期日期 / 交付验收状态 / 收付款状态 / 最近处理时间
				收付款视图：合同 / 交易对方 / 收付方向 / 计划名称 / 计划金额 / 已收付金额 / 计划日期 / 收付款状态
				操作：查看合同 / 维护履行事项 / 添加或修改草稿计划 / 记录交付验收 / 记录收付款结果
				规则：非金额型合同不强制建立收付款计划；已生效合同修改关键计划必须记录变更原因和操作审计
			变更与补充协议
				创建：必须从原合同发起 / 选择变更或补充协议 / 填写原因 / 编辑内容 / 上传附件
				审批：使用独立外部审批关联 / 审批前不改变原合同当前有效内容 / 审批结果幂等同步
				生效：保存生效时间 / 更新当前有效内容 / 保留前后版本 / 维护原合同与变更关系
				规则：补充协议和变更协议不是独立合同类型；原合同完成或终止后的处理按类型规则控制
		系统管理【一级导航，仅管理员和配置人员可见】
			合同分类配置
				配置内容：合同大类 / 合同类型 / 合同子类型 / 交易方向 / 协议性质 / 我方角色 / 适用主体身份
				类型配置：编码 / 名称 / 上级类型 / 启用状态 / 可用模板 / 类型扩展字段 / AI规则 / 履行规则
				操作：新建 / 编辑 / 启用 / 停用 / 发布配置版本 / 查看历史版本
				规则：停用类型不能新建；历史合同绑定原配置版本；发布后只影响新建或重新选择类型的合同
			合同模板配置
				模板库组织：模板分类 / 适用合同类型和子类型 / 适用场景 / 标签 / 常用和收藏
				列表内容：模板名称 / 模板分类 / 适用类型 / 适用场景 / 标签 / 当前版本 / 启用状态 / 更新时间
				查询条件：名称或关键词 / 模板分类 / 合同大类和类型 / 适用场景 / 标签 / 启用状态 / 我的收藏
				操作：新建 / 导入模板文件（Word/DOCX） / 批量导入模板配置（Excel） / 编辑 / 配置变量 / 预览 / 发布版本 / 复制版本 / 收藏 / 启停用
				变量字段库：复用通用字段和类型扩展字段；每个变量绑定字段编码、数据来源、格式化规则和必填校验
				模板差异：模板元数据和版本结构统一；正文条款、变量组合、排版和适用场景可按合同类型、子类型和业务场景不同配置
				规则：新版本只影响新建合同；已生成正文不随模板变化；模板变量必须有来源字段和缺失校验；Excel仅用于批量导入模板元数据和变量映射，不作为默认合同正文模板
			我方主体配置
				操作：引用主数据中的我方主体 / 查看可用主体 / 选择默认主体
				规则：不在本系统维护我方主体主数据；当前按单一主体可用，预留多法人扩展【二期】
			外部连接配置
				连接类型：HR员工系统 / 客户系统 / 供应商系统 / 文件服务 / 外部审批系统 / Dify服务
				操作：配置连接 / 测试连接 / 启停用连接 / 查看连接日志 / 管理密钥
				文件服务：公司已有文件服务底座；合同中心区是其为合同系统分配的业务存储空间，存放PDF / Word / 扫描件 / 附件 / 签署文件 / 导出文件，不属于合同业务代码或菜单
				文件职责：合同系统校验合同业务权限、维护附件关联/版本/审计；文件服务负责物理存储、预览、下载和短期访问链接；数据库不存文件二进制、物理路径或长期公开URL
				文件接口：申请上传 → 文件服务上传 → 上传完成确认并返回file_id/哈希/大小 → 创建附件关联；预览和下载均先校验合同权限后申请短期链接；删除按保留策略归档或清理并记录审计
				规则：密钥密文保存；连接失败不影响历史合同查询；外部接口均记录请求、响应摘要和失败原因
			权限与审计
				角色：系统管理员 / 合同管理员 / 法务 / 业务人员 / 只读用户
				权限配置：复用HR系统角色、菜单和数据范围模型；本系统补充合同类型、模板、字段和合同级授权
				菜单权限：合同中心 / 系统管理
				页面与按钮权限：查看合同 / 新建 / 编辑草稿 / 发起AI任务 / 编辑法律意见 / 提交审批 / 撤回审批 / 撤回签署 / 上传附件 / 预览下载附件 / 删除附件 / 导出下载 / 作废终止 / 查看敏感信息
				数据权限：本人 / 本部门 / 本部门及下级 / 指定组织 / 全部 / 合同负责人 / 合同级授权
				合同类型权限：合同类型是实际授权和校验单位；配置角色可创建、查看和处理的合同类型及其子类型；合同大类不单独授权，由大类下至少一个有权限的启用类型派生可见；大类批量授权只展开为当前类型权限，新类型需重新授权；销售默认销售和服务，HR默认劳动、劳务和顾问，采购默认采购，法务按授权查看
				模板权限：配置角色可使用的模板分类、适用场景和模板；无权限模板不出现在新建合同和常用模板入口
				字段权限：配置字段可见、脱敏、只读、可编辑；薪酬、身份证号、借款利率、担保信息等敏感字段单独授权
				合同级授权：跨部门协作时授予指定用户或角色查看、编辑、法务处理或导出权限；授权范围和有效期可追溯
				审计：合同操作 / AI任务 / 文件访问 / 外部审批同步 / 配置变更 / 导出任务
				规则：一期复用HR基础组织数据范围（本人 / 本部门 / 本部门及下级 / 指定组织等），与合同类型权限取交集；未软删除是数据保留条件，不等于未作废；作废是展示和统计规则，不是权限过滤条件，作废合同可按权限查看但不参与有效业务统计；多部门、多组织叠加范围列入二期；合同级授权只作为指定合同的受控例外并集；审计记录不可被普通业务删除；关键动作记录操作者、时间、来源和结果
				权限过滤规则（系统运行规则，不是独立菜单）
					权限原则：合同大类和合同类型决定字段、模板、AI规则和履行规则；不直接等同于用户可见范围
					默认范围：系统管理员和合同管理员按授权查看；法务查看授权范围内合同；业务人员查看本人创建或负责、所属组织范围内合同；只读用户按分配范围查看
					业务范围：销售人员默认查看销售及服务类合同；HR人员默认查看劳动、劳务及顾问类合同；采购人员默认查看采购合同；实际范围由角色、组织和数据权限配置决定
					敏感范围：员工合同、薪酬、身份证号、借款和担保信息按字段权限脱敏；有合同查看权限不等于有全部字段查看权限
					创建范围：新建合同只展示当前用户有权限创建的合同类型、子类型和模板；合同大类入口由可创建类型派生；不同类型动态加载对应字段
					数据授权：默认按组织和负责人授权；跨部门合同可由合同管理员授予额外查看或编辑权限；合同级授权优先于角色默认范围
					页面展现：不按销售、人力拆独立业系统；统一进入合同中心，在合同台账或履行与收付款页面内选择合同大类，再用合同类型Tab平铺；仅展示当前用户有权限的类型和子类型；工作台统计只计算当前用户可见合同
		工作台经营概览【二期，并入工作台，非独立一级导航】
			合同统计：按大类、类型、生命周期、我方主体、交易对方引用、金额和日期统计
			履行统计：交付验收 / 收付款 / 到期逾期统计
			AI统计：解析成功失败 / 审查任务数量 / 风险等级分布
			规则：作废合同不计入有效业务汇总；统计遵守数据权限；指标口径与工作台复用同一查询服务
	外部依赖（不是本系统业务菜单）
		HR员工、客户、供应商等主体主数据（员工合同统一纳入本系统；员工主数据引用HR系统，不复制）
		公司文件服务 → 合同中心区（物理存储PDF / Word / 扫描件和合同附件）
		外部审批系统
		Dify合同AI专家体
	核心业务闭环
		创建：选择类型和模板 → 引用我方主体及交易对方 → 填写通用和类型内容 → 保存草稿
		智能处理：提交正文版本 → 发起AI解析 → 人工确认解析结果 → 按合同类型发起法律审查
		外部审批：校验提交条件 → 创建外部审批实例 → 合同保持草稿且锁定关键内容 → 接收回调或主动查询
		审批结果：通过 → 待签署；驳回或撤回 → 草稿并恢复编辑；重复回调按外部实例和事件号幂等
		签署生效：上传签署文件 → 校验签署信息 → 确认生效 → 履行中；待签署可撤回 → 原审批实例作废 → 合同回草稿 → 修改后重新提交并生成新审批实例
		履行管理：维护交付验收、履行事项和收付款计划 → 记录实际结果 → 完成或提前终止
		合同变更：从原合同发起变更或补充协议 → 独立审批 → 生效后更新当前内容并保留历史版本
		全程追溯：每次状态、版本、AI、审批、文件和导出操作均写入审计记录
	状态模型
		合同业务状态：草稿 → 待签署 → 履行中 → 已完成；草稿或待签署 → 作废；待签署 → 草稿（撤回签署）；履行中 → 已终止
		外部审批状态：未提交 → 审批中 → 通过；审批中 → 驳回或撤回
		AI解析状态：未发起 → 处理中 → 待确认或已完成；处理中 → 失败
		AI审查状态：未发起 → 处理中 → 待法务确认或已完成；处理中 → 失败
		履行状态：未开始 → 履行中 → 已完成或已终止
		规则：审批中不是合同业务状态；各状态独立存储；页面动作由状态、权限和前置校验共同决定
	实际菜单层级（用于前端导航，不等同于功能树中的所有节点）
		合同中心【一级导航】
			工作台【二级菜单 = 系统首页；含我的待办 / 合同概况 / 最近更新 / 经营概览】
			合同台账【二级菜单】
				页面内包含合同大类选择器和合同类型Tab，按当前用户权限展示
			履行与收付款【二级菜单】
				复用合同大类选择器和合同类型Tab，不新增独立工作区菜单
			合同详情、合同创建、AI处理、审批关联、签署、变更、合同级授权【详情页、流程页或页签，不单独做菜单】
		系统管理【一级导航，仅管理员和配置人员可见】
			基础配置【二级菜单 = 单页手风琴：合同分类 / 合同模板 / 外部连接 / 角色权限 / 操作日志】
			账号管理【二级菜单 = 账号 + 角色 + 数据范围默认值】
			我方主体配置【配置项，归入基础配置，不单独拆成普通业务菜单】
