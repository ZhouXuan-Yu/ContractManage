# Hrcontract 前端统一设计规范

> 状态：首版实施基线
> 生效日期：2026-09-11
> 参考：`D:\WorkProject\ContractManage` 当前合同页面与 HeroUI Pro 官方设计原则

## 1. 设计方向

采用 **Swiss White 合同运营台**：白色为绝对主体，使用中性灰建立信息层级，以国际克莱因蓝
`#002FA7` 标记主操作、当前导航和关键数据。视觉语言来自 Swiss Style：清晰网格、强字阶、
高留白、细边框与严格对齐；玻璃感仅用于粘性顶栏、浮层和关键聚焦区域，避免彩色渐变与过度装饰。

服务对象是合同经办人、法务、审批协作人员和系统管理员。界面优先支持高密度扫描、证据追溯、
状态辨认和连续办理。合同正文、表格、表单及数据大屏均保持白底高对比，状态色只表达业务含义。

## 2. 令牌

权威实现位于 `frontend/src/design-system/tokens.css`。业务组件必须使用语义变量，不散落品牌色值。

| 目的 | 令牌 | 当前值 |
| --- | --- | --- |
| 页面背景 | `--background` | `#F7F7F8`，可叠加 24px 中性网格 |
| 主表面 | `--surface` | `#FFFFFF` |
| 主文字 | `--foreground` | `#111111` |
| 次文字 | `--muted` | `#666A73` |
| 品牌与主操作 | `--accent` | `#002FA7` |
| 成功 / 警告 / 危险 | `--success` / `--warning` / `--danger` | 语义色 |
| 结构线 | `--border` / `--separator` | 中性灰 |
| 基础圆角 | `--cm-radius-md` / `--cm-radius-lg` | `12px` / `20px` |
| 间距 | `--cm-space-*` | 4px / 8px 基准 |

中文使用 Helvetica Neue、苹方、微软雅黑回退链；金额、编号、统计数字使用等宽数字特性。

## 3. 页面骨架

```text
全高侧栏（品牌 / 分组导航 / 当前用户）
  + 半透明粘性上下文栏（页面标题 / 面包屑 / 演示数据状态）
      + 页面头（业务说明 / 主动作）
      + 决策带（对象 / 状态 / 风险 / 下一步）
      + 主要工作区
      + 空态、失败态或降级提示
```

- 桌面主内容最大宽度 `1440px`，左右留白 32–36px；移动端 16px。
- 用户身份和退出操作固定在侧栏底部，不在顶部工具栏重复。
- 工作台先总览后明细；列表页先查询与已应用筛选，再表格与分页；详情页先合同身份和状态，
  再正文、审查、审批、签署、履行、文件与审计。
- 侧栏与主内容是同级布局。移动端侧栏转为紧凑导航，后续组件化时升级为抽屉。

## 4. 组件规则

- 主按钮：一页最多一个主要动作；实心钴蓝。次要动作使用白底描边或文字按钮。
- 危险动作：使用危险色软底，执行前给出对象、影响和不可逆说明。
- 状态：必须有文字；颜色只是辅助。合同业务、审批、AI、文件、履约状态保持独立展示。
- 卡片：白色单层表面、1px 中性边框、极轻阴影；玻璃效果不得牺牲文字对比度。
- 表格：表头使用次级表面；行 hover 只用于可点击行；金额和日期保持列对齐。
- 表单：标签用真实业务字段名；校验紧邻字段；保存失败不清空用户输入。
- 图标：统一 `lucide-react`；图标按钮必须有 `aria-label` 和可发现说明。
- 动效：仅用于展开、覆盖层和状态反馈；高频导航不使用位移动画；遵循
  `prefers-reduced-motion`。

## 5. 功能页模板

| 页面类型 | 必备区块 | 主动作 |
| --- | --- | --- |
| 工作台 | 待办、风险、生命周期、趋势、最近更新 | 新建合同 |
| 合同台账 | 搜索、筛选、已应用条件、表格、分页 | 新建合同 |
| 创建/登记 | 来源说明、字段分组、版本/文件提示、错误汇总 | 保存草稿或确认登记 |
| 合同详情 | 身份带、独立状态、页签、操作记录 | 由后端允许动作决定 |
| AI 审查 | 原文证据、发现列表、来源位置、人工确认 | 确认审查结果 |
| 履行收付款 | 里程碑、计划、异常、凭证 | 记录履行事项 |
| 数据驾驶舱 | 核心 KPI、趋势、风险分布、阶段转化、异常排行 | 导出运营快照 |
| 基础能力 | 模板、相对方、知识库、规则库、权限与集成 | 新增或配置 |
| 系统配置 | 配置说明、列表/表单、影响范围、审计提示 | 保存配置 |

## 6. 迁移策略

正式入口已经迁移为 React。旧 Vue 文件暂时保留作功能对照，但不参与构建。后续按“共享组件 →
真实 API 适配 → 页面替换”的顺序持续收口；不得重新引入 Vue 运行时或复制旧页面样式。

## 7. 验收门槛

1. 1440px、1024px、390px 三档布局无横向溢出或遮挡。
2. 键盘可到达所有操作，焦点清晰，图标按钮有可访问名称。
3. 加载、空、失败、无权限、冲突和成功状态可区分。
4. AI 只做提取、检测、解释和建议，不出现自动批准、签署或放行。
5. 类型检查与构建通过；真实登录、台账、详情、创建和至少一个写操作在浏览器验证通过。
